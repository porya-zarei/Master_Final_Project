| **D-14** | 2026-11-06 | **`locked` and `dead` are modelled as physically DIFFERENT faults.** `dead`: h = 0, the motor delivers nothing, but bearing friction still spins the wheel and still reacts on the structure. `locked`: h = 0 **and** the wheel is jammed — ω̇ = 0 and it transmits nothing to the body | a naive `h = 0` conflates them. The difference is observable in the wheel speed and is asserted by `tests/test_fault_taxonomy.py`. Implemented as a mask applied only when `locked_any` is true, so with no locked wheel the plant executes byte-for-byte the old code (verified: historical path diff 0.000e+00) | in force |
